# 1860, 한양 세책점의 비밀

조선 후기 문화(실학, 서학과 동학, 서민 문화, 진경산수화)를 사료로 탐구하는 중학교 역사② 방탈출 웹앱입니다.
성취기준 [9역11-03], [9역11-04].

- 학생: 표지 → 도입 영상 → 모둠 입장 → 세책점 지도 → 4개 방(퍼즐 12개) → 숨겨진 서고 창고(국학·풍속화·민화, 퍼즐 3개) → 대문(열쇠 5개) → 최종 질문 → 탈출
- 교사: 주소 끝에 `#/teacher` (처음 PIN `1860`) — 제한 시간·PIN 설정, 모둠 기록 인쇄, 시간 추가, 사료 그림 상태 확인
- 서버 없이 작동합니다. 게임 기록은 각 태블릿(브라우저)에 저장됩니다. 이름·학번은 받지 않습니다.

## Cloudflare Pages에 배포 (GitHub 연결)

1. GitHub에 새 저장소(예: `sechaek-escape`)를 만들고 이 폴더를 올립니다.
2. Cloudflare 대시보드 → Workers & Pages → 만들기 → Pages → Git에 연결 → 저장소 선택
3. 빌드 설정
   - 프레임워크 기본값: Vite (또는 없음)
   - 빌드 명령: `npm run build`
   - 빌드 출력 디렉터리: `dist`
4. 저장 및 배포 → `https://sechaek-escape.pages.dev` 같은 주소가 생깁니다.
5. 역사교사 아카이브의 'AI 웹앱' 메뉴에 이 주소를 '바로 사용' 링크로 등록합니다.

GitHub 없이 바로 올리려면: `npm run build` 후 `npx wrangler pages deploy dist --project-name sechaek-escape`

## 표지 QR 코드

표지 오른쪽의 QR 코드는 지금 열린 주소를 자동으로 담습니다. 배포한 주소(예: `https://sechaek-escape.pages.dev/`)로 연 표지를 TV에 띄우면 학생이 태블릿 카메라로 찍어 바로 들어올 수 있어요.
QR을 누르면 TV용으로 크게 보입니다. 다른 주소를 고정하고 싶으면 `src/data/game.js`의 `appUrl`에 적으세요.

## 모둠 진행판 (여러 모둠 한 화면에서 보기)

역사교사 아카이브 안 주소(`/play/sechaek-escape/`)로 열면 작동합니다. 아카이브의 D1을 함께 쓰므로 따로 설정할 것은 없습니다.

1. 교사 화면(`#/teacher`) → **모둠 진행판 열기** → 수업 이름과 제한 시간을 넣고 **수업 열기**
2. 숫자 **4자리 수업 코드**가 나옵니다. 칠판에 적어 주세요.
3. 학생은 모둠 입장 화면의 **수업 코드** 칸에 그 숫자를 넣고 입장합니다. (칸을 비우면 지금처럼 그 태블릿 안에서만 작동)
4. 진행판에 모둠 카드가 나타나고 5초마다 새로 고쳐집니다. 남은 시간, 열쇠, 퍼즐 12칸(회색=아직, 노랑=푸는 중, 빨강=막힘, 초록=완료), 오답·힌트 수가 보이고, **자세히**를 누르면 퍼즐별 첫 답·오답·힌트·시간과 최종 답을 봅니다.
5. 모둠 카드의 **+5분**을 누르면 그 모둠 태블릿의 시간이 15초 안에 늘어납니다.
6. **다른 기기(TV)에서 열 주소 복사**를 누르면 그 주소로 교사 노트북·TV에서도 같은 진행판을 볼 수 있어요.

이름·학번은 받지 않습니다. 수업 기록(모둠 이름, 반, 퍼즐 진행)은 서버에서 3일 뒤 자동으로 지워집니다.
서버와 연결이 끊겨도 게임은 그대로 진행되고, 다시 연결되면 기록이 따라옵니다.

다른 곳에 따로 배포해서 쓸 때는 `src/data/game.js`의 `apiBase`에 아카이브 주소(예: `https://...의-주소/api/sechaek`)를 적으세요. 비워 두면 진행판만 꺼지고 게임은 그대로 작동합니다.
